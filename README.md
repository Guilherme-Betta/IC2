## 🇺🇸 English

### 📌 About the Project
This project aims to organize and analyze a water quality database from the **Piracicaba, Capivari, and Jundiaí (PCJ) river basin**.

The data were collected at the Water Treatment Station (ETA) of the Piracicaba River by **SEMAE**, in partnership with **CENA (Center for Nuclear Energy in Agriculture)**. The project has an agricultural perspective, focusing on water quality for irrigation purposes.

### 🎯 Objectives
The main goal is to apply Machine Learning methods to handle data cleaning and analysis. The specific scripts developed in this repository cover:

* **Preprocessing:** Data cleaning and handling missing values.
* **EDA:** Exploratory and descriptive data analysis.
* **Outlier Detection:** A comparative study between traditional methods and Machine Learning approaches for outlier removal.
* **Modeling:** Application of AI models to analyze water quality variables and their correlations.

* **Documentation:** Jupyter Notebooks

## 🇧🇷 Português

### 📌 Sobre o Projeto
O objetivo deste trabalho é organizar e analisar uma base de dados de qualidade de água na **bacia hidrográfica dos rios Piracicaba, Capivari e Jundiaí (PCJ)**.

Os dados são provenientes da Estação de Tratamento de Água (ETA) do rio Piracicaba, coletados pelo **SEMAE** em parceria com o **CENA (Centro de Energia Nuclear na Agricultura)**. O projeto possui uma perspectiva agrícola, com foco na qualidade da água para fins de irrigação.

### 🎯 Objetivos Específicos
Este repositório contém os scripts necessários para atingir os seguintes objetivos:

* **Pré-processamento:** Limpeza da base de dados e tratamento de valores.
* **AED:** Análise exploratória e descritiva da base de dados.
* **Estudo Comparativo:** Comparação entre o método tradicional para remoção de *outliers* e métodos de Aprendizado de Máquina.
* **Modelagem:** Desenvolvimento e aplicação de modelos de IA para analisar as variáveis de qualidade da água e suas correlações.

### 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **IDE:** Visual Studio Code (VS Code)
* **Reprodutibilidade:** Os códigos foram documentados em formato de células do Jupyter Notebook.
